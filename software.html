Línea 106 - Ayuda inmediata

Un asistente entrenado para escuchar

El software de Luz no reemplaza a un profesional. Está diseñado para contener el primer momento, orientar y derivar con seguridad.

Modelo

GPT-4.1-nano.

Utilidad y eficiencia

Se seleccionó este modelo por su equilibrio entre capacidad analítica y alta velocidad de procesamiento. Esto minimiza el tiempo de latencia en las respuestas, permitiendo interacciones fluidas y naturales sin sacrificar la coherencia. Además, su costo por millón de tokens es altamente accesible ($0,10 USD de entrada y $0,40 USD de salida), lo cual resulta ideal para ejecutar pruebas iniciales escalables optimizando el presupuesto del proyecto.

Seguridad y ética

Se han implementado estrictos parámetros de operación. La configuración del modelo está respaldada por el asesoramiento de profesionales en psicología para garantizar el uso de un lenguaje adecuado y evitar orientaciones erróneas. Asimismo, el sistema cuenta con restricciones absolutas, como la prohibición de emitir diagnósticos, mitigando así cualquier riesgo o consecuencia adversa para el usuario
